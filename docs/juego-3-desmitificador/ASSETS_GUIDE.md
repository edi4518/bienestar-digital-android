# Guía Estética y Assets: Juego 3

## Paleta de Colores
* **Fondo Principal:** `#0F172A` (Azul Oscuro / Dark Mode)
* **AURA / Verdadero (Acierto):** `#06B6D4` (Turquesa Neón)
* **El Ruido / Falso (Error):** `#EF4444` (Carmesí / Rojo Estática)
* **Tarjeta Núcleo / Éxito Final:** `#F59E0B` (Dorado Neón)

## Efectos Visuales Requeridos
* **Fondo dinámico:** Ruido de estática digital que disminuye a medida que el jugador acierta.
* **Animación de Tarjeta:** Rotación en eje Y (3D Flip) de 180° al soltar la tarjeta para revelar la justificación.
